Despre GIS_portal Edineț

Portal WebGIS pentru orașul Edineț, realizat în Visual Studio Code cu Leaflet 1.9.4, Bootstrap 4.6.2 și jQuery 3.7.1, rulat local cu extensia Live Server.

Datele sunt fișiere .shp convertite în GeoJSON și salvate ca variabile JavaScript (lib/*.js) cu scriptul pregateste_date_portal.sh:

  • © OpenStreetMap contributors: clădiri, drumuri, ape, servicii, rețeaua electrică (04.10.2026)
  • CORINE Land Cover 2018: Copernicus Land Monitoring Service
  • Ortofotoplan 2016: serviciul WMS al INDS (geodata.gov.md)
